# Metadados editoriais ainda exigem decisão dos autores

O código e os resultados podem ser reproduzidos, mas uma publicação ou release
público não deve ser criado antes de os responsáveis preencherem:

1. nomes completos, afiliações e ORCID dos autores;
2. autor correspondente e contato institucional;
3. licença do código;
4. licença e condições de redistribuição dos artefatos derivados;
5. arquivo `CITATION.cff`;
6. DOI ou identificador permanente do release.

Esses campos não foram inferidos automaticamente para evitar atribuição de
autoria ou licença sem autorização.
