Glossário do Projeto – Classificação de Glitches do LIGO com IA

PIC Astronomia · Projeto 3 – Ondas Gravitacionais · referência rápida para leitura dos relatórios e do código
Fluxo do projeto: detector mede o strain → baixamos do GWOSC os eventos do GWTC → branqueamento → Q-gram (imagem tempo × frequência) → renderização em cinza → ensemble de 5 CNNs treinadas no Gravity Spy → classe + teste OOD (“a rede conhece este tipo de imagem?”) → Grad-CAM mostra onde a rede olhou. Em paralelo: ridge e filtro casado como diagnósticos físicos.

Fenômeno e detectores

Onda gravitacional
“ondulação” do espaço-tempo produzida, por exemplo, pela fusão de dois buracos negros; viaja à velocidade da luz.
LIGO / Virgo
interferômetros que medem essas ondas: braços de quilômetros cujo comprimento varia uma fração minúscula quando a onda passa.
H1, L1, V1
os detectores: LIGO Hanford, LIGO Livingston e Virgo.
Strain (deformação)
o que o detector mede: variação relativa do comprimento dos braços (~10⁻²¹), registrada 4.096 vezes por segundo.
Glitch
ruído curto e transitório de origem instrumental ou ambiental; pode imitar ou esconder um sinal real.
Chirp (“piado”)
forma típica de uma fusão: o sinal sobe rápido em frequência e amplitude até o choque. Também é uma classe do Gravity Spy.
Massa de chirp
combinação das massas dos dois corpos que determina como a frequência do chirp sobe. No “referencial do detector” ela é multiplicada por (1 + z), o desvio para o vermelho.

Dados e catálogo

GWOSC
portal público de dados do LIGO/Virgo/KAGRA; fonte de todo o strain usado.
GWTC / GWTC-4
catálogo oficial de ondas detectadas; a linha 2.0 usa 218 eventos.
Evento (ex.: GW150914)
uma detecção, nomeada pela data (14/09/2015 foi a primeira).
Canal
par evento + detector (ex.: GW150914 L1). São 654 possíveis, 475 aprovados.
PSD
densidade espectral de potência: quanto ruído há em cada frequência.
Branqueamento (whitening)
dividir os dados pelo ruído típico de cada frequência, para que nenhuma domine e o sinal apareça.
SNR
razão sinal-ruído: quanto o sinal se destaca do ruído; maior = sinal mais forte.

A imagem do sinal

Q-transform / Q-gram
imagem tempo (horizontal) × frequência (vertical), com brilho = energia. É a “foto” que a IA analisa.
Renderização
como os números do Q-gram viram tons de cinza (140 × 170 pixels).
Percentis (canônica)
estica o contraste de cada imagem; fundo preto e ruído realçado.
Escala Gravity Spy (exploratória)
energia de 0 a 25,5 no mapa de cores viridis, convertido em cinza — imita as imagens de treino.
Espectrograma (STFT)
outra imagem tempo × frequência, mais simples; usada no kit didático.

A inteligência artificial

Gravity Spy
projeto em que voluntários rotularam ~8 mil imagens de glitches em 22 classes; é o conjunto de treino.
Classes
os 22 rótulos (Blip, Koi_Fish, Scattered_Light, Chirp, No_Glitch, None_of_the_Above…). No_Glitch = sem glitch; None_of_the_Above = glitch que não cabe nas outras.
CNN / ResNet-18
rede neural para imagens; recebe a foto e devolve uma probabilidade para cada classe.
Treino / validação / teste
imagens para aprender / para ajustar escolhas / para medir o desempenho final, nunca vistas antes.
Seed / ensemble
seed é o ponto de partida aleatório de um treino; o ensemble junta as 5 redes treinadas com seeds diferentes.
Macro-F1
nota de acerto de 0 a 1 que dá o mesmo peso a todas as classes (linha 2.0: 0,945).
Matriz de confusão
tabela “era X, a rede disse Y”; mostra onde a rede se confunde.
Controle de qualidade (QC)
limpeza dos dados de treino; removeu 159 painéis vazios repetidos.
Classificação forçada
a rede sempre escolhe uma classe, mesmo sem reconhecer a imagem — não existe “não sei”.

A rede conhece esta imagem? (OOD)

OOD (fora da distribuição)
imagem diferente demais das de treino; a classe dada pela rede não tem significado.
Mudança de domínio
diferença sistemática entre os dados de treino (Gravity Spy) e os de uso (eventos GWTC).
Distância de Mahalanobis
quão longe a imagem fica, no “espaço interno” da rede, das imagens de treino.
Escore de energia
medida de quão segura a rede está da resposta.
Referência OOD / limiar q99
a referência guarda o “normal” de cada modelo; o q99 é o corte acima do qual só 1% das imagens normais ficam.
reject_ood / review / in_domain_candidate
decisões: rejeitada (fora do domínio) / revisar / parece conhecida.
Validade externa
se o modelo funciona em dados diferentes dos de treino. Resultado atual: negativo (475/475 rejeitados).

Interpretabilidade

Grad-CAM
mapa de calor sobre a imagem mostrando a região que mais pesou na decisão (vermelho = mais).
Atalho (shortcut)
quando a rede decide por algo irrelevante (fundo, bordas, brilho geral) em vez do sinal.

Diagnósticos físicos

Ridge
traça a crista de energia do chirp e estima a massa de chirp a partir da curvatura.
Filtro casado / template
compara os dados com formas de onda teóricas (templates) e mede o encaixe pela SNR.
Condicionado ao catálogo
usa as massas já publicadas como ponto de partida; não serve para descobrir eventos novos.

Projeto e reprodutibilidade

Linha v9 / linha 2.0
versão antiga (90 eventos, Relatório V2, branch v9) / versão atual do professor (218 eventos).
Errata
documento que corrige erros de um relatório já publicado.
Hash (SHA-256)
“impressão digital” de um arquivo: mesmo hash = arquivos idênticos byte a byte.
Reprodutibilidade
outra pessoa, com os mesmos dados e código, chega ao mesmo resultado.
Preregistro
definir antes o teste e o critério de sucesso, para não ajustar a análise até “dar certo”.
Exploratório × confirmatório
exploratório gera hipóteses; confirmatório as testa com regras fixadas antes.
Kit didático
gw_student_kit: versão simplificada para ensino; não gera resultados do projeto.
